Kendago LTV desk

This folder is enough to open the app. The October scores are already in artifacts/.
The raw CSV export is not required.

1. Install Python 3.11 or newer.
2. In this folder, run:

   python3 -m pip install -r requirements.txt
   python3 -m streamlit run app.py

3. Open the local URL that Streamlit prints (usually http://localhost:8501).

On the machine where this was built, ./run_app.sh does the same thing.

The app has three tabs: October campaign calls, a scorer for a new order, and the method.
predictions.csv is the file named in the task brief (order_id, pltv_2y).
